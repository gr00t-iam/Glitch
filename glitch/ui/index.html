You stay in control

  • Every file write shows a diff for approval.
  • Commands use fixed, approved recipes; there is no arbitrary shell string execution.
  • Desktop clicks, typing, browser actions and screenshots each require approval. Unicode typing temporarily uses and restores the clipboard.
  • Remote approvals are available in your Discord channel and here.
  • Chrome uses a separate profile on loopback port 9222. Your existing browser tabs stay separate.
  • Move your mouse to a screen corner to activate the desktop input fail-safe.
  • Glitch must stay open on an awake, unlocked desktop for remote computer tasks.

Command recipes
