Settings & connections

Give Glitch the right tools for your project.

A brain of your own

Glitch runs GGUF models directly on your NVIDIA GPU or CPU. No separate model server is needed.

One context pool serves every stream. Agents borrow available space; when it fills, requests wait rather than allocate extra caches. GPU offloading fits available VRAM without reducing your chosen context. A vision projector must be a separate compatible file; Muse Glimmer uses text and browser DOM tools.

A second pair of eyes

Hybrid mode sends your task and up to 15 recent, redacted actions to the supervisor on errors, repeated actions, or step milestones. Screenshots stay out of cloud audits. Your access setting applies independently.

Use a provider-authorized bridge already running on this PC. Glitch does not collect account passwords, browser cookies, or subscription session tokens. Plan access and limits are determined by that bridge and its provider.

ChatGPT subscription access requires a supported, authorized integration. Claude Pro/Max credentials cannot be used as a third-party API; use an Anthropic API key instead.

Action permissions

When enabled, Glitch can write workspace files, run supported commands, take screenshots and control your desktop or Chrome without individual approval prompts. This also applies to your authorized Discord tasks and stays enabled after restarting. Turn it off to ask before actions again. Only enable it for trusted tasks.

You stay in control

  • With Full Access off, file writes show a diff for approval and computer actions ask first.
  • Full Access keeps workspace boundaries, protected-file checks and fixed command recipes. It does not grant administrator rights or unrestricted shell execution.
  • Unicode typing temporarily uses and restores the clipboard.
  • Discord ownership and channel checks always remain on. Remote approvals are available when Full Access is off.
  • Chrome uses a separate profile on loopback port 9222. Your existing browser tabs stay separate.
  • Stop task remains available. Move your mouse to a screen corner to activate the desktop input fail-safe.
  • Glitch must stay open on an awake, unlocked desktop for remote computer tasks.

Command recipes

Git status, diff and log; Python unit tests; .NET build; PowerShell directory listing. Tests and builds execute project code, so only use trusted projects.

Local storage

Conversations, timeline and correction anchors persist under %LOCALAPPDATA%\Glitch. API keys and the Discord token use Windows data protection.

Your voice, kept local

English dictation uses an offline speech model. Microphone audio stays in memory and is never uploaded or saved.

Hands-free mode keeps your default microphone open while Glitch is running. Wake detection stays local. Saying Hey Glitch starts dictation, not task execution. Silence finishes your draft; Send stays under your control. Mute turns listening off.

Short completion reports only, not terminal logs or every sub-agent action. Listening pauses while Glitch speaks.
